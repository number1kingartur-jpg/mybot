# Закрытый канал · 30 дней

Сгенерировано: scripts/export-closed-channel.mjs

## Как залить

1. Создай **приватный** канал в Telegram.
2. Опубликуй `welcome.txt` и закрепи.
3. По одному посту в день из `day-01.txt` … `day-30.txt` (или планируй через отложку).
4. Ссылку-приглашение в `RESTART_PAID_URL` на Railway.
