# Закрытый канал KINGMODE · 30 дней шаг за шагом

Полная программа подписана. Исходник: `src/closed-program.ts`.

## Два канала — в чем разница

| | **@kingmode_fit (открытый)** | **Закрытый канал** |
|---|------------------------------|---------------------|
| **Зачем** | Познакомиться, доверять | Не слиться, пройти 30 дней |
| **Контент** | Мысли, фактура, Таиланд, иногда наука | Каждый день: движение + одна привычка |
| **Длина** | Пост по теме | Один формат, предсказуемо |
| **Ты** | Автор | Ведущий («сделал» / «тяжело») |
| **Цена** | 0 | Подписка (см. ниже) |
| **Бот** | Кнопка, опционально | Дополнение, не замена |

**Открытый не дублирует закрытый.** В открытом нет «День 14: сделай присед 3×10».

## Структура 30 дней

| Неделя | Дни | Фокус |
|--------|-----|--------|
| 1 | 1–7 | Тело просыпается: базовые движения дома, вода, белок, сон |
| 2 | 8–14 | Привычки: вода, белок ×2, вес, шаги, экран, овощи |
| 3 | 15–21 | Ритм: больше подходов, ходьба, бутылка, полный круг |
| 4 | 22–28 | Закрепление, мини-тест (день 25), план после |
| 5 | 29–30 | Итог, повтор теста, одно решение на следующий месяц |

Каждый день:
- **Движение** 15–20 мин (дом, без зала)
- **Одна привычка** (не диета целиком)
- **Отметка** («сделал» в комментарии)

## Связка с ботом

```
Открытый канал → «Старт 3 дня» (бот, бесплатно)
       ↓
Закрытый канал (30 дней, платно)
       ↓
Личка / коучинг (1490+ THB)
```

После 3 бесплатных дней бот предлагает закрытый канал (`RESTART_PAID_URL`).

## Технически: как запустить

1. Telegram → создать **приватный канал** (название, например «KINGMODE · 30 дней»).
2. Добавить себя и бота (если нужна автовыдача через Tribute / вручную).
3. Собрать тексты:
   ```bash
   npm run build
   node scripts/export-closed-channel.mjs
   ```
   Файлы: `content/closed-channel/welcome.txt`, `day-01.txt` … `day-30.txt`.
4. Закрепить `welcome.txt`, дальше **один пост в день** (или отложка).
5. Railway → `RESTART_PAID_URL=https://t.me/+invite_link`.
6. В открытом канале кнопка «В закрытый» (когда будет пост-продажа).

Оплата на первом этапе: **вручную** (написал «СТАРТ30» → скинул ссылку → оплатил → добавил). Tribute/Stars позже.
